# APG V4 FULL
Авто Партнерская Группа — responsive web app.

## Local
Backend:
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload --port 8000

Frontend:
cd frontend
npm install
npm run dev

Open http://localhost:5173
